# Testing Guide

## Purpose

Testing helps verify that application functionality continues to work as expected.

## Before Creating a Pull Request

Developers should:

1. Run the project's test suite.
2. Check for TypeScript errors.
3. Check for linting errors.
4. Verify the application locally.
5. Review the Git diff.

## Test Categories

### Unit Tests

Unit tests verify individual functions or small pieces of application logic.

### Integration Tests

Integration tests verify that multiple application components work together correctly.

### End-to-End Tests

End-to-end tests verify complete user workflows.

## Pull Request Testing

Every pull request should be checked locally before it is submitted for review.
