# Code Style Guide

## General Principles

- Keep code readable and consistent.
- Prefer clear and descriptive names.
- Keep functions focused on a single responsibility.
- Avoid unnecessary duplication.

## Naming

Use descriptive names for variables, functions, components, and files.

## TypeScript

Prefer explicit types when they improve readability and maintainability.

## Components

Keep reusable components focused and avoid unnecessarily large components.

## Comments

Comments should explain why something is done when the reason is not obvious from the code.

## Formatting

Follow the formatting and linting configuration already provided by the project.
